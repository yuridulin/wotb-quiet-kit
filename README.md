# WoT Blitz 11.21.0 — косметический набор

Единственный артефакт для шаринга — **инструкция**:

- [`INSTRUCTION.md`](INSTRUCTION.md)
- Latest release: <https://github.com/yuridulin/wotb-quiet-kit/releases/latest>

В инструкции: идея, подходы к звуку/прицелу/тихому UI, пути, версии, откат,
ссылки на публичные моды и инструменты. Без скриптов, payload и архивов модов.

## Что внутри

- **Идея** — косметика для 11.21.0: PC-звуки, WoT-style прицел, тихое лобби.
- **Подходы** — какие файлы/каталоги менять, как обходить micropatch overlay,
  как конвертировать DVPL type 4 → type 2, как приглушать бейджи и скрывать
  баннеры.
- **Ссылки** — официальная политика WG, публичные sound/reticle-моды, DVPL
  инструменты.

## Важно

- Большие файлы не передаются и не коммитятся: агент скачивает публичные моды
  по ссылкам из инструкции.
- Скрипты в `agent_kit/` и `quiet_11.21/` — локальная реализация для
  обслуживания; для шаринга они не нужны.
- Пакет привязан к 11.21.0. После обновления игры нужен новый набор.
- Только sound/custom UI/custom reticle. Никаких DLL, автоматизации, aim assist,
  статов или боевых маркеров.
